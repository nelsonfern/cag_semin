# Presentación C (por temas, diseño 2): copia de las diapositivas

La presentación es una página web: https://claude.ai/artifact/RTqiumNMqwUj8oZyQRoLXB (privada hasta
que se comparta desde su menú Compartir). Desde ahí se puede presentar y exportar a PDF o PowerPoint.

Esta carpeta guarda una copia de su contenido para que quede en el repositorio:
- `deck.json`: título, orden de las 31 diapositivas y secciones.
- `slides/<id>.html`: cada diapositiva, con las notas del orador en `<aside>`.

Las imágenes están cargadas en la presentación web (rutas `/_blob/...`) y no se ven abriendo estos
archivos sueltos. Las originales están en [`docs/img/`](../../img/): los dos gráficos y las capturas
de [`docs/img/demo/`](../../img/demo/).

Lo que dice cada integrante: [`guion_C.md`](../guion_B.md). Estructura y tiempos:
[`version_C_temas.md`](../version_B_bloques.md).
