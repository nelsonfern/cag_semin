Martin: recorrer las filas en orden, como el viaje de un documento. Lo importante de la descarga: es “educada” con los sitios oficiales. Hay tres tipos de fuente: HTML (Registro Civil), una página armada en JavaScript (Secretaría de Justicia) y un PDF (la ley impositiva). Las dos huellas SHA-256 (del original y del texto) dicen si cambió el organismo o nuestra extracción. El tokenizer es el del mismo modelo, para contar exactamente lo que va a ocupar.
