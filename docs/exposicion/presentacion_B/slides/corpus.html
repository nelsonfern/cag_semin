Ramiro: la marca “## ” que puso el parser es la que permite cortar. Cada sección recibe un id estable, documento#sN; ese id es lo que el modelo escribe como cita y lo que el código después verifica. Arriba de cada documento van los metadatos (organismo, fuente, fechas). El build_id del corpus es un hash del texto, del tokenizer y de la configuración: si cambia algo, es otro corpus y la caché vieja ya no sirve. Pase: “Este texto es lo que va a la caché. Nelson les muestra cómo.”
